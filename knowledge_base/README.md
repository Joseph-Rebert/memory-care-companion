# Knowledge base (for your caregiver chatbot's RAG)

Generated by `python -m alz_finder.cli build-kb`. Two files:

- **`cases.jsonl`** — the retrieval corpus. One JSON object per *chunk*:
  ```json
  {"id": "12-c0", "text": "....", "metadata": {
     "paper_id": 12, "title": "...", "authors": "...", "year": 2026,
     "venue": "...", "doi": "...", "url": "...", "source": "pubmed",
     "pmcid": "PMC...", "score": 3, "matched_dims": "symptoms,progression,treatment",
     "text_source": "fulltext_xml | pdf | abstract", "oa_status": "open | closed"}}
  ```
- **`analysis.jsonl`** — Claude's distilled per-case analysis (symptoms,
  communication, progression, treatment, caregiver insights, example Q&A). These
  are also folded into `cases.jsonl` as extra retrievable records.

## How to use it (RAG in ~20 lines)

The KB is **embed-ready** — text is chunked; you add the vectors. Example with a
local embedding model + a simple in-memory search:

```python
import json
from sentence_transformers import SentenceTransformer
import numpy as np

model = SentenceTransformer("all-MiniLM-L6-v2")
records = [json.loads(l) for l in open("knowledge_base/cases.jsonl")]
vecs = model.encode([r["text"] for r in records], normalize_embeddings=True)

def search(query, k=5):
    q = model.encode([query], normalize_embeddings=True)[0]
    scores = vecs @ q
    for i in np.argsort(-scores)[:k]:
        m = records[i]["metadata"]
        print(f"{scores[i]:.2f}  {m['title'][:60]}  ({m['text_source']})")
        print("   ", records[i]["text"][:200], "...\n")

search("how do I handle agitation and aggression in the evening?")
```

Then feed the top chunks to your chat model as grounding context, and cite
`metadata.url` so caregivers can read the source.

Swap the embedder/vector store for whatever you use (OpenAI/Voyage embeddings,
Chroma, FAISS, pgvector, etc.) — the JSONL format stays the same.

## Licensing — important
- `oa_status: "open"` chunks may contain verbatim **open-access** full text.
- `oa_status: "closed"` chunks are **abstract-only** (full text is licensed and
  was not stored). Respect this if you redistribute anything.
- Case reports are de-identified but copyrighted. Use for **grounding and design
  insight**; cite the source rather than republishing text wholesale.
